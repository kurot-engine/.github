# Code of Conduct

Kurot welcomes people who participate in good faith and treat others with
respect.

## Expected behavior

- Be constructive, patient, and specific.
- Critique ideas and code rather than people.
- Respect different backgrounds, experience levels, and communication styles.
- Keep technical discussions relevant to the project.
- Accept maintainers' decisions about project scope and direction.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized content,
doxxing, deliberate disruption, and repeated bad-faith behavior are not
tolerated in project spaces.

## Enforcement

Maintainers may edit or remove content, close or lock discussions, reject
contributions, or temporarily or permanently restrict participation when
behavior conflicts with this policy.

For conduct involving a security concern, use the private reporting mechanism
described in `SECURITY.md`. For other sensitive conduct reports, contact an
organization owner privately through an available GitHub channel rather than
posting personal details publicly.

This policy applies to repositories, issues, pull requests, discussions, and
other spaces managed by the Kurot Engine organization.
